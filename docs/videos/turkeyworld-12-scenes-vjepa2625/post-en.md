I trained TurkeyWorld on a single NVIDIA GeForce RTX 4090. The original game is on the left. On the right, a 300.1M-parameter V-JEPA world model uses the same controls, the map, and its own predictions to move the player and enemy. A 4.19M-parameter neural renderer draws each predicted state at 32×32. A 2.98M-parameter upscaler brings it to 128×128, adds wall texture, and composites the original enemy, weapon, and hand sprites. The clip shows four fights, four chases without gunfire, and four navigation runs. The counter shows how fast the neural game computes each frame.
