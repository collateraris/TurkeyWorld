## Непрерывный цикл

`run_vjepa_sr_cycle` не имеет лимита раундов:

1.100 обновлений динамики H180.
2.50 actor/critic updates в её замороженном prior; первоначально20 reward/continue warmup, после смены мира предусмотрена повторная калибровка.
3.64 NAV+64 quiet NPC эпизода Source по360 transitions, затем повтор.

Политика имеет148 входных признаков:state20+128D V-JEPA latent readout, но адаптер хранит полную память. Новая политика создаётся отдельно от RSSM policy; старые actor/critic сохранены. Реальный Source при сборе задаёт наблюдаемое state20; изображения для V-JEPA формируются Base/SR в том же домене. Инициализация/observe не сбрасывают всю историю каждый шаг. Imagination использует только собственный prior и SR, без Source feedback. Сбор маскируетfire, сохраняет quiet HP/alive, включает сложные wall cases и ограниченные64 попытки; исчерпание явно останавливает фазу ошибкой. Это ограничение попыток, не число раундов.

```bash
.venv-ubuntu/bin/python -m turkeyworld.run_vjepa_sr_cycle \
  --run-dir training_runs/vjepa_sr_cycle_20261117
```

Одновременно второй controller не запускать. Для остановки создать `training_runs/vjepa_sr_cycle_20261117/stop.request`: controller передаст запрос активной фазе и сохранит завершённый optimizer boundary. Для продолжения убрать пользовательские stop flags после проверки статуса; checkpoints, Adam, samplers/RNG и round/phase продолжаются. Цикл не запускает GUI.
