# Дистиллированная нейроигра TurkeyWorld на RTX 4090

Игровой ученик — собственная модель TurkeyWorld в стиле V-JEPA с **47 867 140 параметрами активной динамики**. У учителя шага 2625 их 300 057 860. В энкодере ученика шесть блоков, в предикторе семь. Ширина 512, восемь голов внимания и память четырёх последних шагов совпадают с учителем. Это позволяет передать обученные головы игрока, врага и респавна без изменения их входов. Нейрорендер Base32 шага 32909 и апскейлер SR128 шага 7187 используют свои отдельные веса.

## Запуск игры

Из корня проекта установите зависимости в то же окружение, где работают PyTorch с CUDA и нейроигра. На рабочей RTX 4090 использовались PyTorch 2.11.0+cu128, TensorRT 10.13.3.9.post1 и ONNX 1.20.1.

```bash
.venv-ubuntu/bin/python -m pip install -r requirements-tensorrt.txt
RUN=training_runs/vjepa_sr_cycle_20261117/dynamics/diagnostics
VISUAL="$RUN/combat_visual_20261118T143817Z"
STUDENT="$RUN/trt_2625_20261119/student/final.pt"
.venv-ubuntu/bin/python -m turkeyworld.compare_play \
  --world "$STUDENT" --display-base-renderer "$VISUAL/base/renderer.pt" \
  --sr "$VISUAL/sr_sprites/sr.pt" --device cuda --fp16 --trt \
  --smooth --display-size 1024 --source-size 128 --initial-environment combat
```

**Enter** начинает пробу, **WASD** управляет движением, **Q/E** поворачивают, **пробел** стреляет, **T** переключает бой и навигацию, **R** начинает пробу заново. Слева оригинал, справа автономная нейроигра. Счётчик в игровом окне измеряет вывод новых кадров на экран.

При первом запуске на этой видеокарте игровой процесс создаёт два файла `.engine` в `training_runs/tensorrt_engines/`. Один исполняет предиктор V-JEPA. Второй исполняет свёрточную часть RRDB и головы материала, швов, цвета и фактуры. Координаты и события обновляют игровые головы. Base32 и обратная связь по изображению работают в PyTorch. Прозрачность, перекрытие стенами и наложение оружия по-прежнему определяет спрайтовый композитор. Для повторного запуска используется кэш, привязанный к весам, архитектуре, форме тензоров, GPU и версии ПО. Тот же ключ `--trt` доступен в `turkeyworld.neural_play`. Для сравнения с PyTorch FP16 удалите из команды `--trt`. Игра передаёт TensorRT указатели CUDA-тензоров и получает выходы в память PyTorch. [NVIDIA TensorRT Python API](https://docs.nvidia.com/deeplearning/tensorrt/10.x.x/inference-library/python-api-docs.html)

## Как повторить дистилляцию

Нужны исходный чекпойнт учителя, зафиксированные в нём Base/SR для обратной связи и накопленные коллекции Source из обучающего цикла. Для повторного эксперимента задайте новый каталог результата.

```bash
CYCLE=training_runs/vjepa_sr_cycle_20261117
.venv-ubuntu/bin/python -m turkeyworld.distill_vjepa \
  --teacher "$CYCLE/dynamics/diagnostics/combat_clips_20261119T023930Z/world.pt" \
  --cycles "$CYCLE/cycles" --output "$CYCLE/dynamics/diagnostics/student48m_rerun" \
  --steps 600 --batch 12 --lr 1e-4 --seed 19117
```

Для каждого режима взяли по 40 обучающих и восемь отдельных проверочных эпизодов. Всего получилось 1 440 обучающих и 288 проверочных окон по шесть команд. В бою часть окон привязана к выстрелам, попаданиям, гибели и респавну. Учитель получает действительное стартовое состояние и записанные команды, затем предсказывает свои состояния и наблюдения. Ученик учится воспроизводить визуальное представление, следующие два латентных прогноза и выходы боевых голов. Набор окон и контрольные суммы файлов записаны в `split.json`.

После 600 обновлений лучший суммарный результат на проверочных окнах дал шаг дистилляции **500**. Ошибка энкодера MSE снизилась с 0,91083 до 0,000344, предиктора — с 1,33572 до 0,000112. Ошибка Huber боевых голов составила 0,000540. Входы движения и боя, 1 236 тензоров вне энкодера и предиктора и закреплённая обратная связь Base/SR сохранены от учителя. Полный файл `final.pt` занимает 483 МиБ и включает служебные веса прежнего рендерера для совместимости с игровым загрузчиком. SHA-256 выбранного чекпойнта — `26e941a658868bcf42ce633f5be0976e4513138ef04cf4674b953beb9f602203`.

## Качество на 180 шагах

Внешняя проверка охватывает 20 эпизодов — 14 записанных ранее сцен и шесть новых стартов. В них 3 600 игровых тиков. Стартовые отрезки с теми же состояниями и шестью командами отсутствуют среди обучающих и внутренних проверочных окон дистилляции. Справа модель получает только старт, карту и команды. Оба движка TensorRT работали во время записи.

| Показатель | Ученик с TRT против учителя PyTorch | Ученик с TRT против оригинала |
| --- | ---: | ---: |
| Тики, на которых совпали все четыре игровых события | 3 600 / 3 600 | 3 596 / 3 600 |
| Совпадение тика и клетки респавна | 8 / 8 | 8 / 8 |
| Максимальное отклонение игрока, клетки | 0 | 1,531 |
| Максимальное отклонение врага, клетки | 0,000145 | 1,655 |
| Средняя абсолютная разница RGB128, шкала 0–255 | 0,713 | 14,177 |

Дистилляция сохранила и сильные стороны учителя, и его ошибки. У самого учителя относительно оригинала совпали события на тех же 3 596 тиках. На двух новых боях встречались расхождения в боевых событиях. В опубликованную нарезку вошли четыре боя, четыре погони и четыре навигационных сцены с теми же стартами и командами, что в предыдущей версии. Цифры поверх правого окна рассчитаны по новому прогону ученика.

## Скорость игрового кадра

На одной RTX 4090 ученик показал **40,7 FPS в PyTorch FP16 и 53,4 FPS с TensorRT**, ускорение в 1,31 раза. Это скорость подготовки кадра для игры, измеренная без ожидания следующего игрового тика. Оригинал и отрисовка интерфейса исключены. Игровые часы идут с частотой 30 Гц. Нагрузка фонового цикла обучения и валидации меняется по ходу раунда.

| Сцена H180 | PyTorch FP16, FPS | TensorRT, FPS | TensorRT p95, мс/кадр |
| --- | ---: | ---: | ---: |
| Бой | 39,2 | 50,7 | 34,9 |
| Погоня | 37,1 | 46,7 | 36,8 |
| Навигация | 46,9 | 66,5 | 30,5 |

Использован один чекпойнт ученика. В каждом режиме один и тот же отрезок H180 прошёл дважды в обоих вариантах с обратным порядком второго замера. Получилось 1 080 кадров на вариант. В замер входит весь шаг с нейрорендером, апскейлом, увеличением для интерактивного окна и получением RGB1024 на CPU. Загрузка, компиляция и прогрев вынесены из замера.
